SistemaMP Centinela — arquitectura

Cómo se conecta el sistema

Un solo camino de guardado que se reparte en tres direcciones al mismo tiempo: este computador, la nube y, si se conecta, un respaldo paralelo. Así el sistema sigue funcionando aunque se corte internet, y nunca depende de un solo lugar.

siempre, sin depender de internet ruta principal de sincronización opcional, se conecta por computador
Por qué offline-first

Si se corta internet a mitad de un turno, nada se pierde: el sistema sigue leyendo y guardando en este computador, y cuando vuelve la señal, sincroniza solo con la nube.

Por qué 3 destinos, no 1

La nube es la fuente oficial y compartida entre todos. Este computador es la copia de trabajo diaria. La carpeta paralela es un tercer respaldo, fuera de Supabase por completo.

Un detalle importante

La carpeta de respaldo se conecta por computador, no para todo el sistema — el botón "Conectar carpeta" (en Configuración) guarda esa elección solo en el navegador donde se apretó. Si otro equipo abre el sistema, tiene que conectar su propia carpeta.
