FORMULARIO frmLogin (opcional, recomendado: oculta la contraseña con asteriscos)

1. Editor de VBA (Alt+F11) → Insertar → UserForm. En Propiedades: (Name) = frmLogin, Caption = Conectar a SistemaMP
2. Agrega:
   - TextBox  (Name) = txtEmail
   - TextBox  (Name) = txtClave   · PasswordChar = *
   - CommandButton (Name) = cmdEntrar · Caption = Entrar · Default = True
   - CommandButton (Name) = cmdCancelar · Caption = Cancelar · Cancel = True
   (y dos Label con "Correo" y "Contraseña")
3. Doble clic en el formulario y pega este código:

Option Explicit
Public Aceptado As Boolean

Private Sub cmdEntrar_Click()
    If Trim$(txtClave.Value) = "" Then
        MsgBox "Escribe tu contraseña.", vbInformation
        Exit Sub
    End If
    Aceptado = True
    Me.Hide
End Sub

Private Sub cmdCancelar_Click()
    Aceptado = False
    Me.Hide
End Sub

Private Sub UserForm_Activate()
    txtClave.SetFocus
End Sub
